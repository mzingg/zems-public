# Setup

Every ZEMS library runs on JDK 25 or newer and is released on Maven Central under the group `dev.zems.lib`, with no
extra repository or token. Each library's setup page holds its dependency snippet:

| Library | Coordinate            | Setup                                          |
| ------- | --------------------- | ---------------------------------------------- |
| common  | `dev.zems.lib:common` | [common setup](../10_lib/common/docs/setup.md) |
| value   | `dev.zems.lib:value`  | [value setup](../10_lib/value/docs/setup.md)   |
